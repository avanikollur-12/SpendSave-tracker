# 💰 SpendSave

> Automatically save your spare change while gaining smarter insights into your spending habits.

---

## 📖 About

SpendSave is a smart savings web application that helps users build better financial habits effortlessly.

Instead of requiring users to manually save money, SpendSave automatically rounds up every transaction to the nearest whole amount and transfers the spare change into savings.

Alongside automatic savings, the application provides interactive spending analytics and personalized financial insights, helping users understand where their money goes and identify unnecessary expenses.

---

## 🚨 Problem Statement

Many people struggle to save money consistently because:

- Saving requires conscious effort and discipline.
- Small amounts spent during daily transactions often go unnoticed and are lost instead of being saved.
- Users lack meaningful insights into their spending patterns, making it difficult to reduce unnecessary expenses.

---

## 💡 Solution

SpendSave solves these problems by:

- 💳 Automatically rounding up every transaction.
- 💰 Converting spare change into savings.
- 📊 Visualizing spending habits using interactive charts.
- 🤖 Providing smart financial insights and analytics.
- 🎯 Encouraging consistent saving without changing spending behavior.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/<your-github-username>/SpendSave-tracker.git
```

### Navigate

```bash
cd SpendSave
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

Backend runs on:

```
http://127.0.0.1:5000
```

### Frontend

Simply open

```
frontend/index.html
```

or use VS Code Live Server.
